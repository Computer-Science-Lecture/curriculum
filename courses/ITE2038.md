## 한 줄 판정

ER 모델링·SQL·웹 애플리케이션 세 과제를 모두 제출했고 모두 동작하는 모양은 갖췄지만, 정작 데이터베이스 과목에서 평가받아야 할 관계 설계는 매번 JSON 문자열과 varchar로 우회했고, 세 과제 전부 한 번만 실행해봤으면 잡혔을 버그를 그대로 제출했다.

- **[치명적] 제출된 결과 파일은 프로그램이 만든 것이 아니다**  
  `Assignment2/2-1/lib/manager.py:24–27, 117–125`  
  학생 모드의 커밋이 빈 함수다. 개인 주소록에 대한 create / update / remove 는 전부 메모리에만 반영되고 디스크에 쓰이지 않는다. 유일하게 파일을 쓰는 곳은 load() 인데, 방금 읽은 프레임을 그대로 되쓰기 때문에 내용이 바뀌지 않는다.
- **[치명적] Step 3의 핵심 요구(email 컬럼 분리 저장)가 두 버전 모두 빠져 있다**
