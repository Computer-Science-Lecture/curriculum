# 한양대 CS 커리큘럼 아카이브

학부 5년(2015–2020) 동안 제출한 수업 코드 **16개 저장소**를, 저장소마다 독립 리뷰어를 붙여
정독·빌드·실행하고 근거와 함께 평가한 기록입니다.

**→ [cse.jiun.dev](https://cse.jiun.dev)** 에서 읽는 것을 권합니다. 모든 지적이
실제 파일·행 번호로 연결되고, 그 자리에서 원본 코드를 펼쳐 볼 수 있습니다.

## 왜 코드가 아니라 리뷰를 공개하는가

정답 코드는 이미 인터넷에 많습니다. 드문 것은 **학부생 코드가 실제로 어떻게 틀리는지에 대한
구체적인 기록**입니다. 이 저장소의 코드는 D+부터 B까지이고 문서화된 결함이 많습니다.
그래서 "내 코드를 참고하라"가 아니라 **"내가 어디서 틀렸는지 보라"** 로 공개합니다.

## 구성

- `courses/` — 과목별 노트 (요구사항, 함정, 참고자료)
- `reviews/` — 코드 감사 보고서 16편 (HTML)
- 각 저장소 루트의 `report.html` — 같은 보고서의 오프라인 사본

## 감사 방법

저장소마다 리뷰어 한 명이 독립적으로 조사했습니다. 공통 지침은 ① 모든 지적에 `경로:행번호` 인용
② 싸게 검증 가능하면 빌드·실행해 실제 출력을 증거로 사용 ③ 확인하지 못한 것은 "미검증"으로 명시
④ README 주장과 구현을 대조 ⑤ 저장소가 작으면 짧은 보고서가 정답.

게시 전 전 건에 대해 구조 검증, 시크릿 스캔, headline 주장 원본 대조를 거쳤습니다.
